🔒 Security & Privacy Guarantees

  • 100% Local-First: No analytics, telemetry, or cloud databases. All costs and token logs reside in a local SQLite file.
  • Credential Protection: Your API keys are passed transparently to LLM providers. AIMeter never captures, logs, or stores your secret keys.
  • Payload Safety: The proxy only extracts and records token count numbers and model names. Your actual prompts, code, and response texts are never logged or stored.
  • Claude Subscription Tracker: Claude Code cost is estimated by matching token usage metrics in local CLI log files. Other providers track direct proxy traffic.
